Unit 1

Differential Calculus

Limits, Continuity, Differentiability, Mean Value Theorem, Maxima & Minima

Limits & Continuity Derivatives MVT Very Important for Exam
📐
Important Formulas — Unit 1
▼
Standard Limits
lim(x→0) sinx/x = 1 lim(x→0) tanx/x = 1 lim(x→0) (eˣ-1)/x = 1 lim(x→∞) (1+1/n)ⁿ = e lim(x→a) (xⁿ-aⁿ)/(x-a) = naⁿ⁻¹
Continuity Conditions
f is continuous at x=a if: 1. f(a) exists 2. lim(x→a) f(x) exists 3. lim(x→a) f(x) = f(a) Left limit = Right limit = f(a)
Differentiation Rules
d/dx[uv] = uv' + vu' d/dx[u/v] = (vu'-uv')/v² d/dx[f(g(x))] = f'(g)·g'(x) d/dx[xⁿ] = nxⁿ⁻¹ d/dx[eˣ] = eˣ
Implicit Differentiation
If F(x,y)=0: dy/dx = -∂F/∂x / ∂F/∂y For ax²+2hxy+by²=c: dy/dx = -(ax+hy)/(hx+by)
Mean Value Theorem
If f continuous on [a,b] and differentiable on (a,b): ∃ c ∈ (a,b) such that f'(c) = [f(b)-f(a)]/(b-a) Rolle's: f(a)=f(b) → f'(c)=0
Maxima/Minima Test
Find: f'(x) = 0 → critical pts f''(x) < 0 → Local Maximum f''(x) > 0 → Local Minimum f''(x) = 0 → use f'''(x) test OR sign change of f'(x)
Leibnitz Theorem (nth Derivative)
If y = sin⁻¹x: (1-x²)y'' - xy' = 0 (1-x²)yₙ₊₂-(2n+1)xyₙ₊₁-n²yₙ=0
L'Hôpital's Rule
If lim f(x)/g(x) = 0/0 or ∞/∞: lim f(x)/g(x) = lim f'(x)/g'(x) Apply repeatedly if needed
📝 Part A — 2 Mark Questions
2 Marks ⭐⭐⭐ Q1. Evaluate: lim(x→-2/3) (9x² - 12x - 4) ▼
Direct Substitution (Polynomial → Just plug in!)
x = -2/3: = 9(-2/3)² - 12(-2/3) - 4 = 9(4/9) + 8 - 4 = 4 + 8 - 4 = 8

For any polynomial, limit = f(a). Just substitute directly!

2 Marks ⭐⭐⭐ Q2. Find dy/dx if ax² + 2hxy + by² = c ▼
Implicit Differentiation — differentiate both sides w.r.t x
2ax + 2h(y + x·dy/dx) + 2by·(dy/dx) = 0 2ax + 2hy + (2hx + 2by)dy/dx = 0 (2hx + 2by)dy/dx = -(2ax + 2hy) ∴ dy/dx = -(ax + hy) / (hx + by)
2 Marks ⭐⭐ Q3. What is a saddle point? ▼
A point where f_x = 0 and f_y = 0 but is NEITHER maximum NOR minimum. The function increases in some directions and decreases in others. Condition: D = f_xx·f_yy - (f_xy)² < 0 Example: f(x,y)=x²-y² at origin is a saddle point
📝 Part B — 8/10 Mark Questions
8 Marks ⭐⭐⭐ Q4. Find values of a and b so that f(x) = {ax+2b, x≤0 | x²+3a-b, 0<x≤2 | 3x-5, x>2} is continuous everywhere ▼
Step 1: Condition at x = 0
Left limit (x→0⁻): a(0)+2b = 2b Right limit (x→0⁺): 0+3a-b = 3a-b For continuity: 2b = 3a-b → 3a - 3b = 0 → a = b ...(1)
Step 2: Condition at x = 2
Left limit (x→2⁻): 4+3a-b Right limit (x→2⁺): 3(2)-5 = 1 For continuity: 4+3a-b = 1 → 3a - b = -3 ...(2)
Step 3: Solve equations (1) and (2)
From (1): a = b Substitute in (2): 3a - a = -3 2a = -3 → a = -3/2 ∴ a = -3/2, b = -3/2
8 Marks ⭐⭐⭐ Q5. State Mean Value Theorem and verify for f(x) = x² - 4x + 3 in [1, 4] ▼
Statement of MVT
If f is: (1) Continuous on closed interval [a,b] (2) Differentiable on open interval (a,b) Then ∃ at least one c ∈ (a,b) such that: f'(c) = [f(b) - f(a)] / (b - a)
Verification for f(x) = x²-4x+3 on [1,4]
f is polynomial → continuous & differentiable ✓ f(1) = 1 - 4 + 3 = 0 f(4) = 16 - 16 + 3 = 3 [f(4)-f(1)]/(4-1) = (3-0)/3 = 1 f'(x) = 2x - 4 Set f'(c) = 1: 2c - 4 = 1 → c = 5/2 = 2.5 Since 2.5 ∈ (1,4) → MVT VERIFIED ✓
8 Marks ⭐⭐⭐ Q6. If y = sin⁻¹x, show that (1-x²)y'' - xy' = 0 ▼
Step 1: Find y'
y = sin⁻¹x y' = 1/√(1-x²) → √(1-x²) · y' = 1
Step 2: Square both sides
(1-x²)(y')² = 1
Step 3: Differentiate
(1-x²)·2y'·y'' + (y')²·(-2x) = 0 Divide by 2y': (1-x²)y'' - xy' = 0 ✓
8 Marks ⭐⭐⭐ Q7. Find maxima and minima of f(x) = 3x⁴ - 4x³ - 12x² + 12 ▼
Step 1: Find f'(x) and critical points
f'(x) = 12x³ - 12x² - 24x = 12x(x² - x - 2) = 12x(x-2)(x+1) Critical points: x = 0, x = 2, x = -1
Step 2: f''(x) test
f''(x) = 36x² - 24x - 24 At x = 0: f''(0) = -24 < 0 → LOCAL MAXIMUM f(0) = 12 At x = 2: f''(2) = 144-48-24 = 72 > 0 → LOCAL MINIMUM f(2) = 3(16)-4(8)-12(4)+12 = 48-32-48+12 = -20 At x = -1: f''(-1) = 36+24-24 = 36 > 0 → LOCAL MINIMUM f(-1) = 3+4-12+12 = 7
Answer
Local Maximum: f(0) = 12 at x = 0 Local Minima: f(2) = -20 at x = 2 f(-1) = 7 at x = -1

Unit 2

Partial Derivatives & Functions of Several Variables

Euler's Theorem, Chain Rule, Taylor's Series, Lagrange's Method, Extreme Values

Partial Differentiation Euler's Theorem Optimization High Weightage
📐
Important Formulas — Unit 2
▼
Euler's Theorem
If u is homogeneous of degree n: x·∂u/∂x + y·∂u/∂y = n·u For modified (u = f(v), v homo. deg n): x·∂u/∂x + y·∂u/∂y = n·f(v)/f'(v)
Chain Rule
If z=f(x,y), x=g(t), y=h(t): dz/dt = (∂z/∂x)(dx/dt)+(∂z/∂y)(dy/dt) If z=f(x,y), x=x(u,v), y=y(u,v): ∂z/∂u=(∂z/∂x)(∂x/∂u)+(∂z/∂y)(∂y/∂u)
Taylor's Series (2 variables)
f(x,y) at (a,b): = f(a,b) + [(x-a)f_x+(y-b)f_y] + (1/2!)[(x-a)²f_xx+2(x-a)(y-b)f_xy +(y-b)²f_yy] + ... At (0,0): a=0, b=0
Conditions for Extreme Values
Find: f_x=0, f_y=0 → critical points D = f_xx·f_yy - (f_xy)² D > 0, f_xx < 0 → Maximum D > 0, f_xx > 0 → Minimum D < 0 → Saddle point D = 0 → Inconclusive
Lagrange's Multiplier Method
To find extrema of f(x,y,z) subject to constraint g(x,y,z)=0: ∇f = λ∇g ∂f/∂x=λ∂g/∂x ∂f/∂y=λ∂g/∂y ∂f/∂z=λ∂g/∂z Then use constraint to find λ
Clairaut's Theorem
If f has continuous second partial derivatives: ∂²f/∂x∂y = ∂²f/∂y∂x (Mixed partials are equal!)
Total Differential
dz = (∂z/∂x)dx + (∂z/∂y)dy Approximate change: Δz ≈ (∂z/∂x)Δx + (∂z/∂y)Δy
Modified Euler (sin⁻¹, tan⁻¹)
If u = sin⁻¹(v), v homogeneous deg n: x∂u/∂x + y∂u/∂y = n·tan(u) [n=1/2 common] If u = tan⁻¹(v), v homogeneous deg n: x∂u/∂x + y∂u/∂y = n·sin(2u)/2
📝 Part A — 2 Mark Questions
2 Marks ⭐⭐⭐ Q1. Prove ∂²f/∂x∂y = ∂²f/∂y∂x for f = x³+y³+z³+3xyz ▼
∂f/∂x = 3x² + 3yz ∂²f/∂y∂x = 3z ∂f/∂y = 3y² + 3xz ∂²f/∂x∂y = 3z ∴ Both equal 3z → Clairaut's Theorem verified ✓
2 Marks ⭐⭐⭐ Q2. If z=x²+y², x=t², y=2at, find dz/dt ▼
dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt) = (2x)(2t) + (2y)(2a) = 2t²(2t) + 2(2at)(2a) = 4t³ + 8a²t = 4t(t² + 2a²)
📝 Part B — 8/10 Mark Questions
8 Marks ⭐⭐⭐ Q3. If u=f(x-y, y-z, z-x), prove ∂u/∂x + ∂u/∂y + ∂u/∂z = 0 ▼
Let p=x-y, q=y-z, r=z-x → u=f(p,q,r)
∂p/∂x=1, ∂p/∂y=-1, ∂p/∂z=0 ∂q/∂x=0, ∂q/∂y=1, ∂q/∂z=-1 ∂r/∂x=-1, ∂r/∂y=0, ∂r/∂z=1 ∂u/∂x = f_p(1)+f_q(0)+f_r(-1) = f_p - f_r ∂u/∂y = f_p(-1)+f_q(1)+f_r(0) = -f_p + f_q ∂u/∂z = f_p(0)+f_q(-1)+f_r(1) = -f_q + f_r Adding all three: ∂u/∂x + ∂u/∂y + ∂u/∂z = 0 ✓
10 Marks ⭐⭐⭐ Q4. Expand eˣsiny as a Taylor's series at (0,0) up to third degree terms ▼
Compute all partial derivatives at (0,0)
f = eˣsiny → f(0,0)=0 f_x = eˣsiny → f_x(0,0)=0 f_y = eˣcosy → f_y(0,0)=1 f_xx = eˣsiny → f_xx(0,0)=0 f_xy = eˣcosy → f_xy(0,0)=1 f_yy = -eˣsiny → f_yy(0,0)=0 f_xxx = eˣsiny → 0 f_xxy = eˣcosy → 1 f_xyy = -eˣsiny → 0 f_yyy = -eˣcosy → -1
Taylor's formula at (0,0)
f(x,y) = f + xf_x + yf_y + (1/2!)(x²f_xx+2xyf_xy+y²f_yy) + (1/3!)(x³f_xxx+3x²yf_xxy+3xy²f_xyy+y³f_yyy)+... = 0 + 0 + y(1) + (1/2)(0 + 2xy(1) + 0) + (1/6)(0 + 3x²y(1) + 0 + y³(-1)) eˣsiny = y + xy + x²y/2 - y³/6 + ...
6 Marks ⭐⭐⭐ Q5. If u=sin⁻¹[(x+y)/(√x+√y)], prove x·∂u/∂x + y·∂u/∂y = ½ tan u ▼
Check homogeneity of v = sin u
v = (x+y)/(√x+√y) v(tx,ty) = (tx+ty)/(√(tx)+√(ty)) = t(x+y)/(√t(√x+√y)) = t^(1/2)·v ∴ v is homogeneous of degree n = 1/2
Apply Euler's theorem to v=sin u
x·∂v/∂x + y·∂v/∂y = (1/2)v = (1/2)sin u But ∂v/∂x = cos u · ∂u/∂x cos u(x·∂u/∂x + y·∂u/∂y) = (1/2)sin u x·∂u/∂x + y·∂u/∂y = (sin u)/(2cos u) = (1/2)tan u ✓
10 Marks ⭐⭐⭐ Q6. Find greatest and least distances from (3,4,12) to sphere x²+y²+z²=1 ▼
Distance from point (3,4,12) to origin: d = √(3²+4²+12²) = √(9+16+144) = √169 = 13 Sphere has centre O=(0,0,0), radius r=1 Greatest distance from (3,4,12) to sphere = d + r = 13 + 1 = 14 Least distance from (3,4,12) to sphere = d - r = 13 - 1 = 12

Key formula: For point P and sphere with centre C and radius r: max/min distance from P to sphere = |PC| ± r

8 Marks ⭐⭐⭐ Q7. Examine f(x,y) = x⁴+y⁴-2x²-2y²+4xy for extreme values ▼
Step 1: Critical points (set f_x=0, f_y=0)
f_x = 4x³-4x+4y = 0 → x³-x+y=0 ...(1) f_y = 4y³-4y+4x = 0 → y³-y+x=0 ...(2) Add (1)+(2): x³+y³=0 → x=-y Substitute y=-x in (1): x³-x-x=0 x(x²-2)=0 → x=0,±√2 Critical points: (0,0), (√2,-√2), (-√2,√2)
Step 2: D test at each point
f_xx=12x²-4, f_yy=12y²-4, f_xy=4 D = f_xx·f_yy - (f_xy)² At (0,0): D=(-4)(-4)-16=0 → Inconclusive At (√2,-√2): f_xx=20, f_yy=20 D = 400-16=384>0, f_xx=20>0 → MINIMUM f(√2,-√2) = 4+4-4-4-8 = -8 At (-√2,√2): Similarly → MINIMUM, f=-8
8 Marks ⭐⭐⭐ Q8. Find minimum of x²+y²+z² given ax+by+cz=p (Lagrange) ▼
F = x²+y²+z² - λ(ax+by+cz-p) ∂F/∂x=0: 2x-λa=0 → x=λa/2 ∂F/∂y=0: 2y-λb=0 → y=λb/2 ∂F/∂z=0: 2z-λc=0 → z=λc/2 Use constraint: a(λa/2)+b(λb/2)+c(λc/2)=p λ(a²+b²+c²)/2 = p → λ = 2p/(a²+b²+c²) Minimum = x²+y²+z² = λ²(a²+b²+c²)/4 = p²/(a²+b²+c²)

Wallis Formula King's Property Partial Fractions Important Tricks
📐
Important Formulas — Unit 3
▼
Wallis Formula (Reduction)
∫₀^(π/2) sinⁿx dx = ∫₀^(π/2) cosⁿx dx n odd: (n-1)(n-3)···2 / n(n-2)···3 n even: (n-1)(n-3)···1·(π/2) / n(n-2)···2 e.g. cos⁷: (6·4·2)/(7·5·3) = 16/35
Properties of Definite Integrals
∫ₐᵇf(x)dx = ∫ₐᵇf(a+b-x)dx ∫₀ᵃf(x)dx = ∫₀ᵃf(a-x)dx ← KING'S ∫₋ₐᵃf(x)dx = 2∫₀ᵃf(x)dx [if f even] ∫₋ₐᵃf(x)dx = 0 [if f odd]
Standard Integration Formulas
∫dx/(x²+a²) = (1/a)tan⁻¹(x/a)+C ∫dx/√(a²-x²) = sin⁻¹(x/a)+C ∫dx/√(x²-a²) = ln|x+√(x²-a²)|+C ∫dx/√(x²+a²) = ln|x+√(x²+a²)|+C
Integration by Parts
∫u·dv = u·v - ∫v·du ILATE rule for choosing u: I-Inverse trig, L-Log, A-Algebraic T-Trigonometric, E-Exponential
Partial Fractions
Linear: A/(x-a) Repeated: A/(x-a) + B/(x-a)² Quadratic: (Ax+B)/(x²+bx+c) Then integrate each separately
Area & Arc Length
Area = ∫ₐᵇ y dx (or ∫∫ dA) Area of ellipse = πab Arc length = ∫ₐᵇ √(1+(dy/dx)²) dx Surface of revolution (x-axis): S = 2π∫ₐᵇ y√(1+y'²) dx
Complete the Square
x²+bx+c = (x+b/2)²+(c-b²/4) e.g. x²-6x+13 = (x-3)²+4 Then use standard formula: ∫dx/((x-3)²+4) = (1/2)tan⁻¹((x-3)/2)+C
King's Property — Key Trick
I = ∫₀^(π/2) √sinx/(√sinx+√cosx)dx Using ∫₀ᵃf(a-x)dx: I = ∫₀^(π/2) √cosx/(√cosx+√sinx)dx 2I = ∫₀^(π/2) 1·dx = π/2 ∴ I = π/4
📝 Part A — 2 Mark Questions
2 Marks ⭐⭐⭐ Q1. Prove ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx ▼
Let t = a-x, then dt = -dx When x=0 → t=a; when x=a → t=0 ∫₀ᵃ f(x)dx = ∫ₐ⁰ f(a-t)(-dt) = ∫₀ᵃ f(a-t)dt = ∫₀ᵃ f(a-x)dx ✓
2 Marks ⭐⭐⭐ Q2. Evaluate ∫₀^(π/2) cos⁷x dx ▼
n=7 (odd) → Wallis formula: = (n-1)(n-3)(n-5) / n(n-2)(n-4)(n-6)·(2/1) wait: = (6)(4)(2) / (7)(5)(3) = 48/105 = 16/35

n odd: multiply all even numbers down to 2 divided by all odd numbers down to 1 (no π/2 factor)

2 Marks ⭐⭐⭐ Q3. Evaluate ∫ dx/(x²-6x+13) ▼
Complete the square: x²-6x+13 = (x-3)²+4 ∫dx/((x-3)²+2²) = (1/2)tan⁻¹((x-3)/2)+C
📝 Part B — 8/10 Mark Questions
8 Marks ⭐⭐⭐ Q4. Evaluate ∫₀^(π/2) √sinx/(√sinx+√cosx) dx using King's Property ▼
Let I = ∫₀^(π/2) √sinx/(√sinx+√cosx) dx ...(1) Using King's property [replace x by π/2-x]: sin(π/2-x)=cosx, cos(π/2-x)=sinx I = ∫₀^(π/2) √cosx/(√cosx+√sinx) dx ...(2) Add (1)+(2): 2I = ∫₀^(π/2) (√sinx+√cosx)/(√sinx+√cosx) dx 2I = ∫₀^(π/2) 1 dx = π/2 ∴ I = π/4
8 Marks ⭐⭐⭐ Q5. Evaluate I = ∫₀^(π/2) log sin x dx ▼
Let I = ∫₀^(π/2) log sinx dx ...(1) Using property: I = ∫₀^(π/2) log cosx dx ...(2) Add (1)+(2): 2I = ∫₀^(π/2) log(sinx·cosx) dx = ∫₀^(π/2) log(sin2x/2) dx = ∫₀^(π/2) log(sin2x)dx - ∫₀^(π/2) log2 dx For ∫₀^(π/2) log(sin2x)dx: Let 2x=t → ∫₀^π (1/2)log(sint)dt = I [by half-period] 2I = I - (π/2)log2 ∴ I = -(π/2)log2 or -π/2 · ln2
8 Marks ⭐⭐⭐ Q6. Evaluate ∫(3x-2)/[(x+1)²(x+3)] dx by partial fractions ▼
(3x-2)/[(x+1)²(x+3)] = A/(x+1) + B/(x+1)² + C/(x+3) Multiply both sides by (x+1)²(x+3): 3x-2 = A(x+1)(x+3) + B(x+3) + C(x+1)² x = -1: -5 = B(2) → B = -5/2 x = -3: -11 = C(-2)² = 4C → C = -11/4 x = 0: -2 = 3A + 3B + C -2 = 3A - 15/2 - 11/4 = 3A - 41/4 3A = -2+41/4 = 33/4 → A = 11/4 ∫ = (11/4)ln|x+1| + 5/[2(x+1)] - (11/4)ln|x+3| + C = (11/4)ln|(x+1)/(x+3)| + 5/[2(x+1)] + C
8 Marks ⭐⭐⭐ Q7. Find the area enclosed by the ellipse x²/a² + y²/b² = 1 ▼
From ellipse: y = (b/a)√(a²-x²) Area = 4∫₀ᵃ (b/a)√(a²-x²) dx Let x = a sinθ → dx = a cosθ dθ When x=0→θ=0; x=a→θ=π/2 √(a²-x²) = a cosθ Area = 4(b/a)∫₀^(π/2) a cosθ · a cosθ dθ = 4ab∫₀^(π/2) cos²θ dθ = 4ab · π/4 = πab ✓

Special case: Circle (a=b=r) → Area = πr²

8 Marks ⭐⭐ Q8. Surface area of solid: rotate y=2x+1, x=0 to x=3 about x-axis ▼
S = 2π∫ₐᵇ y√(1+(dy/dx)²) dx dy/dx = 2 → √(1+4) = √5 S = 2π∫₀³ (2x+1)√5 dx = 2π√5 [x²+x]₀³ = 2π√5 [(9+3)-(0)] = 2π√5 · 12 = 24π√5

Double Integral
∫∫ f(x,y) dA = ∫ₐᵇ[∫_{g₁(x)}^{g₂(x)} f(x,y)dy]dx Evaluate inner integral first, then outer integral
Polar Coordinates
x = r cosθ, y = r sinθ x²+y² = r² dA = r dr dθ ← DON'T FORGET r! ∫∫f(x,y)dA = ∫∫f(rcosθ,rsinθ)·r dr dθ
Change of Order of Integration
1. Draw the region of integration 2. Identify boundaries (curves) 3. Find intersection points 4. Rewrite limits in new order 5. Evaluate
Triple Integral
∫∫∫ f(x,y,z) dV = ∫∫∫ f dx dy dz Volume = ∫∫∫ dV Evaluate innermost first
Spherical Coordinates
x=r sinφ cosθ y=r sinφ sinθ z=r cosφ dV = r² sinφ dr dφ dθ For sphere r=a: r:0→a, φ:0→π, θ:0→2π Volume = (4/3)πa³
Cylindrical Coordinates
x=r cosθ, y=r sinθ, z=z dV = r dr dθ dz Useful for cylinders and cone-shaped regions
Common Volume Results
Sphere x²+y²+z²=a²: V=(4/3)πa³ Tetrahedron x+y+z=1: V=1/6 Hemisphere: V=(2/3)πa³ Cylinder r=a, 0→h: V=πa²h
Region Identification (Change Order)
∫₀¹∫_{x²}^{2-x}: y=x² (parabola), y=2-x (line) Meet when x²=2-x → x=1 (y=1) Change: y:0→1, x:0→√y PLUS y:1→2, x:0→2-y
📝 Part A — 2 Mark Questions
2 Marks ⭐⭐⭐ Q1. Find ∫₋₁² ∫ₓ^(x-2) dy dx ▼
∫₋₁² ∫ₓ^(x-2) dy dx = ∫₋₁² [y]ₓ^(x-2) dx = ∫₋₁² [(x-2)-x] dx = ∫₋₁² (-2) dx = [-2x]₋₁² = -4-(-2·-1) = -4-2 = -6
2 Marks ⭐⭐⭐ Q2. Find ∫₀¹∫₀²∫₀³ xyz dx dy dz ▼
Since limits are constants, can separate: = [∫₀¹ z dz][∫₀² y dy][∫₀³ x dx] = [z²/2]₀¹ · [y²/2]₀² · [x²/2]₀³ = (1/2)(2)(9/2) = 9/2
📝 Part B — 8/10 Mark Questions
8 Marks ⭐⭐⭐ Q3. Change order of integration: ∫₀¹∫_{x²}^{2-x} xy dy dx and evaluate ▼
Step 1: Identify region — y=x² and y=2-x meet at (1,1)
Original: x:0→1, y:x²→2-x After change of order: Region 1: y:0→1, x:0→√y Region 2: y:1→2, x:0→2-y
Step 2: Evaluate each part
I₁ = ∫₀¹∫₀^√y xy dx dy = ∫₀¹ y[x²/2]₀^√y dy = ∫₀¹ y²/2 dy = [y³/6]₀¹ = 1/6 I₂ = ∫₁²∫₀^(2-y) xy dx dy = ∫₁² y[(2-y)²/2] dy = (1/2)∫₁² y(4-4y+y²) dy = (1/2)∫₁² (4y-4y²+y³) dy = (1/2)[2y²-4y³/3+y⁴/4]₁² = (1/2)[(8-32/3+4)-(2-4/3+1/4)] = (1/2)[24/3-32/3-3+4/3-1/4] ... = 3/8 Total I = 1/6 + 3/8 = 4/24+9/24 = 13/24
8 Marks ⭐⭐⭐ Q4. Using polar coordinates, evaluate ∫₀ᵃ∫₀^√(a²-x²) (x²+y²) dy dx ▼
Region: first quadrant of circle x²+y²=a² Polar: x=rcosθ, y=rsinθ, x²+y²=r² dA = r dr dθ Limits: r:0→a, θ:0→π/2 I = ∫₀^(π/2)∫₀ᵃ r²·r dr dθ = ∫₀^(π/2) dθ · ∫₀ᵃ r³ dr = [θ]₀^(π/2) · [r⁴/4]₀ᵃ = (π/2) · (a⁴/4) = πa⁴/8
8 Marks ⭐⭐⭐ Q5. Volume of solid bounded by x=0, y=0, z=0, x+y+z=1 by triple integrals ▼
Limits: x: 0→1 y: 0→1-x z: 0→1-x-y V = ∫₀¹∫₀^(1-x)∫₀^(1-x-y) dz dy dx = ∫₀¹∫₀^(1-x) (1-x-y) dy dx = ∫₀¹ [(1-x)y - y²/2]₀^(1-x) dx = ∫₀¹ [(1-x)²-(1-x)²/2] dx = ∫₀¹ (1-x)²/2 dx = (1/2)·[-(1-x)³/3]₀¹ = (1/2)(1/3) = 1/6
8 Marks ⭐⭐⭐ Q6. Volume of sphere x²+y²+z²=a² using spherical coordinates ▼
Spherical: x=r sinφ cosθ, y=r sinφ sinθ, z=r cosφ dV = r² sinφ dr dφ dθ Limits: r:0→a, φ:0→π, θ:0→2π V = ∫₀^2π∫₀^π∫₀ᵃ r²sinφ dr dφ dθ = ∫₀^2π dθ · ∫₀^π sinφ dφ · ∫₀ᵃ r²dr = [θ]₀^2π · [-cosφ]₀^π · [r³/3]₀ᵃ = 2π · [1+1] · a³/3 = 2π · 2 · a³/3 = 4πa³/3 ✓

🔥 Must-Know Tricks
King's Property Trick
∫₀^(π/2) f(sinx)/[f(sinx)+f(cosx)] dx = π/4 ALWAYS! Works for √sinx, sinx, sin²x etc.
Log sin x Result
∫₀^(π/2) log(sinx)dx = -π/2 · log2 ∫₀^(π/2) log(cosx)dx = -π/2 · log2 Both are same! Memorize!
Euler's Theorem Shortcut
Check if u is homogeneous of degree n → x∂u/∂x + y∂u/∂y = nu For sin⁻¹(v) where v is degree n: → x∂u/∂x + y∂u/∂y = n·tan(u)
Polar Conversion
Circle x²+y²=a²: First quadrant: r:0→a, θ:0→π/2 Full circle: r:0→a, θ:0→2π ALWAYS add extra r in dA=r dr dθ!
Volume of Tetrahedron
x+y+z=1 (with x,y,z≥0): V=1/6 ax+by+cz=d: V=d³/(6abc) Sphere r=a: V=4πa³/3
Lagrange Min x²+y²+z²
Given ax+by+cz=p: Min value = p²/(a²+b²+c²) MEMORIZE THIS RESULT! Comes every year!
